# 植物证据与参考影像

species-evidence.json 记录七物种的文献约束、建立顺序及物理模型边界。photo-attribution.json 列出全部本地参考照片的作者、原始地址、来源页面和 CC 许可证；原文件保留，非云谷个体照片，不作为个体尺度或材料标定数据。

sources.json 保存校园官方报道的文字证据及原始图片链接。未取得校园新闻图片重分发授权，故未将校园图片下载到公开素材目录；这些报道只能支持植物存在记录。

物种形态来源：NC State Extension、Flora of China / 中国植物志。木材材性边界参考 USDA Wood Handbook；叶片等效弯曲参数属于工程先验，NASA 风阻方程不提供本植物的实测风阻系数。

后续校准所需：个体 asset ID、定位、树高胸径冠幅、带尺叶片正反面与花、环绕照片、固定机位风摆、根区土壤含水与质地、同机位跨季节观测。这些尚未取得，不在模型中伪造。
