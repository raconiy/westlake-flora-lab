# 校园植物影像来源

本目录保留3条校官网来源及其3个原始图片URL，未保存官网照片。原图引用从官网新闻HTML的detailContent脚本字符串解码提取，未完成图片视觉核验；可能包含新闻截图或拼图，不能假定一定是适合标定的全树照片。

未找到可确认的图片重分发授权，故不下载到可发布素材目录、不直接嵌入网站。sources.json 中 originalImageUrl 已记录，localFile 为 null，downloaded 为 false。

这些页面可以支持校园植物存在的文字证据，不能代替具尺度的个体影像和测量。应由成员打开原文确认照片、取得授权或上传自行拍摄影像，再加入可展示素材。不得把其他大学的银杏照片标成西湖大学。

推荐采集：全树四向照片、围绕植株一圈重叠图像、叶片正反面和花的尺度照片、固定机位风摆视频、同机位跨季节复拍。记录日期、校区、asset ID、尺度和授权主体。
