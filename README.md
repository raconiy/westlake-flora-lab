# 西湖·生境 · Westlake Flora Lab

公开展示：https://raconiy.github.io/westlake-flora-lab/

云谷校园植物的程序化研究原型。React + Three.js；七种植物，可观察地上植株、根系与土壤剖面、茎和叶，独立控制年龄、年内季节、风与重力。

## 本版

- 桂花种子、胚根、真叶幼苗与分枝阶段；对生交互叶序、叶柄和腋生四裂小花。
- 连续的早期根系与根颈衔接，分尺度阴影与手动观察相机。
- 独立的生长和季节时间轴；可保存、导入、导出本机参数快照。
- 协作界面显示实际健康配置、账号数量和任务交付证据。
- 鸡爪槭连接的出苗弯钩、子叶、逐节幼轴和后续对生叶；既成木质节点持续保留，单个顶端器官闭合实际茎尖。掌裂叶使用曲线齿缘和浅折面，尺寸、节距及时序仍待校准。
- 桂花使用持久曲轴和局部节点框架；早龄叶数与数学叶面积保留，所有投影变化作为诊断记录，不以旧直轴像素分布充当植物学真值。
- 鸢尾与麦冬弯曲叶条的法线使用真实局部曲面的对偶梯度；刷新先恢复已保存场景，避免先生成不相关的成年银杏。

## 运行与发布

Node.js 24：

```sh
npm ci
npm run dev
npm test
npm run build
```

推送 main 后，GitHub Actions 自动测试、构建并发布 GitHub Pages。Vite base 为 `/westlake-flora-lab/`，更改仓库名时同时更新 vite.config.ts。

## 多人建议与助手

右下角“建议与助手”或“协作中枢”可直接使用公网窗口。不同访客的建议统一保存在云端 D1，附带当前场景；助手通过已授权的本机 GPT-Load / gpt-6.1-sol / high 异步回答、整理提案。对话按访客会话隔离，可恢复历史；建议看板公开并显示真实处理状态。

流程：收集建议 → 模型整理 → 主控审查派工 → 隔离代码任务 → 类型与结构检查 → 主控整合 → GitHub Actions 发布。收到建议、模型返回、检查通过、代码整合和网站部署是不同状态。失败记录保留，不以“已收到”冒充完成。公众输入不会直接执行任意命令或自动合并源代码。

公网服务持续保存记录；现场模型执行依赖已启动的本机网关和出站 relay。电脑或 relay 离线时，页面显示离线并保留排队记录。生产无人值守仍需常驻主机及运维安排。

源代码包含 [本机执行层](infra/local/README.md) 与 [共享后端](infra/community/README.md)。公开源码不包含账号密码、OAuth 文件、网关密钥、运行日志或任务数据库。

## 模型范围与来源

本项目是未校准的程序化几何与力学近似；并非校园个体扫描还原，也不是完整植物生理求解器。形态与物候来源在“研究依据”中列出；种子萌发时点、器官尺寸、生长曲线和材料参数含明确的工程先验。根系水分响应为示意，尚无实测根系或完整土壤水力、光合作用、繁殖和衰老求解。有限叶批的衰老使用颜色与尺寸渐变代理，未求解离层和落叶轨迹；单个顶芽未求解质量、阻力或周年休眠。枝条仍采用集总转角近似；沿程柔度和后台模型传输候选均未启用。

银杏、桂花、香樟有校园文字来源；其余物种为杭州地区候选，校园分布待确认。银杏物种参考图片来自 NC State Plant Toolbox，不标为云谷照片。作者、CC 许可证与原始链接见 [图片署名](public/references/photo-attribution.json)。
